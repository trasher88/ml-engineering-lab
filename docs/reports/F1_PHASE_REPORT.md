# F1 - Data Engineering & Classical ML: Базовый ML-пайплайн

## Цель фазы
Построить воспроизводимый ML-пайплайн для классификации технических вопросов: выбрать и подготовить реальные данные, разделить их без обнаруженных пересечений похожих записей, обучить простую базовую модель (baseline) и объективно оценить её качество.

Модель определяет тематику вопроса - databases, linux, programming или systems — по тексту публикации Stack Exchange. Она не генерирует ответы и не оценивает их техническую правильность.

**Итог:** получен измеримый baseline, с которым можно сравнивать нейросетевые модели следующих фаз. Метрики относятся к классификации исходного раздела публикации, а не к способности решать технические задачи.

## Использованные алгоритмы и методы
Этап	Алгоритмы и методы	Для чего применялись
F1.1–F1.3	Фиксация версии источника, SHA-256, воспроизводимый отбор с seed=42	Получение одного и того же набора вопросов и контроль целостности данных
F1.4	Нормализация HTML/Markdown, точная дедупликация, фильтр по длине	Очистка текста и исключение непригодных записей
F1.5	EDA: распределение классов, среднее, медиана, процентили	Исследование состава корпуса до обучения
F1.6	Символьный TF-IDF (n-граммы 3–5), cosine similarity ≥ 0,92, Union-Find	Поиск похожих вопросов/ответов и объединение их в группы
F1.6	StratifiedGroupKFold	Разделение на Train/Validation/Test без разрыва вычисленных групп
F1.7	Словный TF-IDF (униграммы и биграммы) + Logistic Regression	Обучение классификатора по Train; векторизатор также обучался только на Train
F1.7–F1.8	Accuracy, Precision, Recall, F1, Macro F1, Confusion Matrix, bootstrap	Измерение качества, анализ ошибок и неопределённости оценки
F1.9	Сверка JSON-аудитов, контрольных сумм, размеров выборок и метрик	Проверка согласованности итогового отчёта

**Главный результат Фазы 1:** реализован полный путь от исходных данных до проверенного классификатора — с воспроизводимой подготовкой корпуса, защитой от обнаруженных дубликатов между выборками и количественной оценкой качества. Абсолютное отсутствие семантических утечек этот метод не гарантирует.

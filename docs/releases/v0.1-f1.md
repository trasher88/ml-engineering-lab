# v0.1-f1 — Data Engineering & Classical ML

**Статус:** черновик описания релиза. Опубликовать после подтверждения F1.9 и GitHub Actions на коммите релиза.

Первый учебный релиз ML Engineering Lab: полный проверенный путь от происхождения технических данных до baseline-классификатора и анализа ошибок.

## Включено в релиз

- F1.1–F1.3: Python-инфраструктура, manifest/provenance, online/offline ingestion с SHA-256.
- F1.4–F1.5: воспроизводимая очистка и агрегированный EDA.
- F1.6: группировка близких дубликатов по вопросу/ответу, разделение 60/20/20 с проверкой пересечений вычисленных групп.
- F1.7: TF-IDF + Logistic Regression, fit только на train, validation/test оценка.
- F1.8: Error Analysis без повторного обучения и публикации исходных Q&A.
- F1.9: итоговый отчёт, формируемый из согласованных JSON-аудитов.

## Воспроизведение

1. Установить зависимости по фазовым `requirements-*.txt` (инструкции в `docs/steps/`).
2. Скачать pinned dataset в локальную директорию и проверить SHA-256; данные не коммитятся.
3. Выполнить `scripts.download_data`, `scripts.clean_data`, `scripts.eda_data`, `scripts.split_data`, `scripts.train_classical`, `scripts.analyze_classical`.
4. Выполнить `python -m scripts.build_f1_report --expect-rows 3040 --expect-test 608 --check`.
5. Запустить offline-тесты F1.1–F1.9.

## Ограничения

- Лицензия зеркала датасета CC BY-NC-SA 4.0, индивидуальная атрибуция исходных постов отсутствует. Данные и обученные веса не включены.
- Нулевое пересечение выявленных лексических групп не исключает семантических/авторских утечек.
- Классификатор определяет source-domain технического вопроса, а не достоверность ответа.
- В GitHub Actions запускаются синтетические тесты и проверка метаданных; полное обучение проводится локально.
- Пока нет лицензии на код — не считать репозиторий автоматически лицензированным для переиспользования.
